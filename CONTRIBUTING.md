# Contributing to Star Catcher Deluxe

Thank you for your interest in contributing to **Star Catcher Deluxe**!

## Getting Started

1. Fork the repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/DilumindaPeiris/Star-Catcher-Deluxe-Game.git
   ```
3. Create a feature branch:
   ```bash
   git checkout -b feat/new-star-archetype
   ```
4. Open `index.html` in your browser to test your changes live.
5. Commit your work following [Conventional Commits](https://www.conventionalcommits.org/):
   ```bash
   git commit -m "feat(stars): add Void Pulse star archetype"
   ```
6. Push to your branch and open a Pull Request!
